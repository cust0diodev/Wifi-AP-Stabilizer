# Histórico

## 1.1.0

- Aplicativo WinForms com API WLAN nativa e monitoramento de BSSID.
- Botão estável durante consultas automáticas.
- Cliques aguardam consultas em andamento.
- Estado visual atualizado por snapshots, sem leitura de campos em mutação.
- Liberação ao fechar e suspensão das tentativas quando a liberação falha.
- Cronômetro monotônico para intervalos.
- Logs com rotação, deduplicação e recuperação de falhas de gravação.
- Testes simulados de comportamento, interface e interoperabilidade.
- Projeto do Visual Studio, build e CI.
- Identificadores de rede extraídos para configuração local.
